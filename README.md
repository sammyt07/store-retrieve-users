# Store Retrieve Users
This is a simple Python, SQLite script that creates a database table, prompts the user for their name and age, stores this information, and spits it back out.

### Requirements:
- Python 3.13.1 or earlier

### Installation and Run
1) Open a terminal on your desktop (or anywhere on your computer), and type:
```bash
git clone https://github.com/sammyt07/store-retrieve-users.git
cd store-retrieve-users
```
2) If you're on Windows, then type `python main.py`
3) If you're on MacOS, then type `python3 main.py`
